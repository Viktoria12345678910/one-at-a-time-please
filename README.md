# ⋆˚࿔ one at a time please 𝜗𝜚˚⋆
## ⁺‧₊˚ ཐི⋆Descritption⋆ཋྀ ˚₊‧⁺
Hey there ˶ᵔ ᵕ ᵔ˶. This program is aiming to ease decision fatigue and freeze from a large number of tasks. Many of us have heard the phrase devide and conquer, it can be great advice but sometimes when instead of 3 tasks at you look back 15 it can feel overwhelming.That is why  instead of showing you everything you need to do this program only shows one task at a time, hence the name.

## ⁺‧₊˚ ཐི⋆Features⋆ཋྀ ˚₊‧⁺

### ୨Tasks୧
The features are quite simplistic currently as this is a first version. Most importantly you can add, view, complete and delete tasks.

### ୨Threads୧
Each task is attached to a thread. A thread represents your projects you are working on. Threads as well as tasks can be added, viewed, deleted and archived. A thread is archived when all the tasks in a thread are comleted, this does not affect your ability to interact with the thread, the devide issymbolical more to let you know that all the tasks are completed.

### ୨Charachter୧
You can add your faavorite charachter to keep you company while you work. Any other image will do to be honest. Best format is 1:1 ratio it will be scaled to 500px by 500px

### ୨Pomodoro୧
This program offers a pomodoro timer that can be adjusted according to your prefrence. And your charachter will also be there

### ୨Themes୧
All the themes are stored in the theme folder by default there are 2. Light theme and dark theme. QSS fromat is used for them so if you like you can make your own

### ୨Languages୧
Currently this program offers 3 languages. English, polish and ukranian. the languages only affect the interface you can write the task names and deskription in your prefered language
